# STACK

A lightweight web console for a home multi-gym setup. Reads in data from an ESP32 module.

## Features
- Lift Visualizer (animated weight stack, range-of-motion track, and rep counter for whatever handle is loaded)
- Handle selector (Lat Pulldown, Seated Row, Chest Press, Leg Extension, Shoulder Press)
- Mobile/Tablet-first layout designed to fit on one screen with no scrolling

## Status
Currently uses simulated or file-based data for development. Future versions will read live data directly from the sensor via an ESP32 bridge that also runs and locally hosts a web server.
